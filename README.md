## 299 元/年这一档，够谁用、不够谁用

这一档的配置是 1 核 / 512MB 内存 / 10GB SSD / 双向 500GB 月流量。下面这份清单是编辑判断，不是实测结果，也没有官方说明背书。

**够用的场景：**

- 个人博客、Hexo/Hugo 这类静态站，日均 PV 几百到几千
- 小型 WordPress，插件不多、不装重型主题
- RSS 聚合、Telegram bot、定时爬虫这类常驻小脚本
- Linux 练手、临时环境、跳板机、轻量代理中转

**不够用的场景：**

- Docker 集群，512MB 内存起两个容器就顶到天花板
- 高并发动态站，MySQL 一跑起来内存就吃紧，swap 一开等于拿硬盘顶着
- 大流量视频中转，500GB 是双向计费，看几部 4K 就见底
- 要 Windows，这个系列以 Linux 为主

打算装 WordPress + MySQL 的话，449 那档更实际：内存翻倍、流量从 500GB 到 800GB，多出来的钱主要买的是不用天天盯着内存曲线。
